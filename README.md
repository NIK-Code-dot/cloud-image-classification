# Cloud Image Classification

An AI-powered image classification web application with a FastAPI backend and a web frontend.

## 🚀 Live Demo

**[Open Cloud Image Classification App](https://nik-code-dot.github.io/cloud-image-classification/frontend/)**

## 🛠️ Technologies Used

- Python
- FastAPI
- Machine Learning
- HTML, CSS, JavaScript
- GitHub Pages
- Render

## 📱 How to Use

1. Open the Live Demo link.
2. Upload an image.
3. Click **Analyze**.
4. View the prediction result.
